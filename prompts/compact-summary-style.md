# 자동 요약 카드: 간결한 표기 규칙

## 근거와 적용 범위

- 사용자가 제공한 상향 카드와 조정 카드 스크린샷에서 표현 규칙을 추출했다. 첫 네 장은 같은 상향 예시이며 마지막 장은 조정 예시다.
- 이미지의 영웅·수치는 표기 참고 자료이며 현재 패치 사실을 검증한 자료로 사용하지 않는다.
- 이 규칙은 `summary_text.py`의 문장 변환과 `summary_cards.py`의 이미지 배치에 적용한다. `monitor.py`가 변환·렌더링·카드 버전 갱신을 연결한다.
- `engineering-harness.md`에 따른 수용 기준과 검증 방법은 `compact-summary-task.md`에 기록한다.

## 기본 표현

`[조건/특전] 기술명 변경 항목 이전 값 → 이후 값`

- 한 줄에 한 변경을 담는다. 같은 기술에 속한 다음 줄은 기술명을 반복하지 않고 들여써 묶을 수 있다.
- 영웅명은 이름표로 표시하고 본문에서 반복하지 않는다.
- `~이/가`, `~에서 ~으로`, `증가했습니다/감소했습니다` 같은 문장 표현은 의미가 유지되는 범위에서 없앤다.
- 공식 기술명·영웅명·수치 항목은 임의로 다른 이름으로 바꾸지 않는다.
- `처치 불가 생명력 한계치`를 `생명력`으로 바꾸는 등 서로 다른 수치 항목으로 읽힐 축약은 하지 않는다.
- 감소/증가 방향이 화살표 값에 드러나면 문장 끝에 같은 설명을 반복하지 않는다.

## 수치와 조건 보존

- 알려진 이전·이후 값은 `175 → 200`, `3초 → 2.5초`, `20% → 25%`처럼 표시한다.
- 원문에 변화량만 있으면 `궁극기 비용 -6%`처럼 표시하고 이전·이후 값을 만들어 넣지 않는다.
- `%`와 `%p`를 바꾸지 않는다. `20% → 25%`를 임의로 `+5%`라고 줄이지 않는다.
- 초·미터·퍼센트·탄환당·틱당 등 단위와 기준을 보존한다. 소수점 정밀도를 임의로 낮추지 않는다.
- `[주요 특전]`, `[보조 특전]`, `(5대5)`, `(6대6)`, 보조 발사, 적중 시, 적에게 보이는 효과 등 적용 범위를 남긴다.
- 수치가 없는 변경은 `적에게 보이는 시각 효과 감소`처럼 짧은 구절로 표현한다. 상황·대상·부정·예외를 없애서 뜻을 바꾸지 않는다.
- 여러 수치가 섞인 문장은 항목과 각 수치를 먼저 대응시킨 뒤 줄인다. 대응이 불명확하면 필요한 원문 표현을 유지한다.

## 상향·하향·조정 표기

- 숫자의 증감과 플레이어에게 유리한지 여부를 구분한다. 재사용 대기시간·궁극기 비용 감소는 일반적으로 상향이다.
- 각 변경에 상향 `↑`, 하향 `↓`, 확인된 혼합 변경 `↔`을 대응시킨다. 근거가 부족하면 `?`와 원문 문장을 판별 필요 카드에 표시한다.
- 영웅의 변경이 전부 상향이면 상향 카드, 전부 하향이면 하향 카드에 묶는다.
- 상향과 하향이 함께 있으면 영웅을 조정 카드에 한 번 표시하고, 내부 항목마다 `↑`/`↓`를 나눈다.
- 일반전과 스타디움은 같은 영웅이어도 별도로 분류하고 모드를 표시한다. 개발자 설명은 판단에서 제외하며, 시각·음향 변경은 회색 점으로 남긴다. 구체적인 수치 항목 기준은 `balance-classification.md`를 따른다.
- 색상은 상향 민트, 하향 분홍/빨강, 조정 주황을 기본으로 한다. 색만으로 구분하지 않고 화살표나 이름도 표시한다.

## 배치 참고

- 일반/스타디움 → 상향/하향/조정 → 돌격/공격/지원 순서로 카드를 분리한다. 한 장에는 한 모드·유형·역할만 포함한다. 본문 36px, 영웅명 38px, 역할 40px, 제목 64px로 고정하며 줄 높이는 52px이다.
- 역할군이 생략되면 수집한 공식 글의 명시적 역할 제목을 참조한다. 확인되지 않으면 별도의 역할 확인 필요 카드로 표시한다.
- 바뀐 뒤의 값과 정성적 변경의 핵심 구절을 강조한다.
- 길어지면 의미 단위에서 줄바꿈하거나 카드를 나눈다. 조건이나 변경 항목을 단순히 잘라내지 않는다.
- 이미지 뷰어의 검은 여백, 닫기 버튼, `2/7` 같은 화면 UI는 카드 디자인에 포함하지 않는다.
- 원문 공식 이미지 전송 제외 정책은 유지한다. 이 문서는 봇이 직접 만드는 요약 카드에만 해당한다.

## 변환 예시

아래 긴 문장은 스크린샷의 표기를 설명하기 위해 재구성한 예시다.

| 문장형 예시 | 간결한 표기 |
| --- | --- |
| 메카의 기본 생명력이 175에서 200으로 증가했습니다. | 메카 기본 생명력 175 → 200 |
| 궁극기 비용이 6% 감소했습니다. | 궁극기 비용 -6% |
| 불사 장치의 재사용 대기시간이 22초에서 20초로 감소했습니다. | 불사 장치 재사용 대기시간 22초 → 20초 |
| 주작 부활의 시전 시간이 3초에서 2.5초로 감소했습니다. | 주작 부활 시전 시간 3초 → 2.5초 |
| 보조 특전 니트로 부스트의 추가 속도가 125%에서 100%로 감소했습니다. | [보조 특전] 니트로 부스트 추가 속도 125% → 100% |

## 구현 시 검증할 항목

1. 변환 전후 영웅·기술·조건·이전 값·이후 값·단위가 일치한다.
2. 변화량만 있는 문장에서 이전·이후 값을 생성하지 않는다.
3. 상향과 하향이 섞인 영웅은 조정으로 묶고 각 항목의 방향은 유지한다.
4. 숫자 없는 변경, 원문 그대로 둬야 하는 모호한 표현, 소수·퍼센트·여러 모드 조건을 보존한다.
5. 짧은 표기와 강조를 적용한 카드가 잘리거나 겹치지 않는지 렌더링해 확인한다.
