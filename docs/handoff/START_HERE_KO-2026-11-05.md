# 다른 컴퓨터에서 이어서 작업하기

이 폴더 또는 ZIP 전체를 새 컴퓨터의 AI에게 전달하고 아래 문장을 함께 보내세요.

> 이 패키지의 AI_HANDOFF.md를 먼저 읽고 작업을 이어줘. https://github.com/wldnjs826/overwatch-patch-bot 의 최신 코드를 확인한 뒤, 포함된 수정본을 적용하고 오류 검사를 해줘. 검사에 통과하면 GitHub에 올리고, 가능하면 main 브랜치에 반영한 다음 GitHub Actions 결과까지 확인해줘. 유료 AI API는 사용하지 말고, 기존 state.json과 Discord 웹훅 설정을 유지해줘. 기존 코드와 충돌하면 최신 변경을 보존하며 해결하고, 무엇을 수정하고 어디까지 반영했는지 알려줘. 이후 수정도 이 코드와 인수인계 내용을 기준으로 이어서 해줘.

GitHub 로그인은 새 컴퓨터에서 진행하면 됩니다. 이 패키지에는 비밀번호, API 키, Discord 웹훅이 없습니다.

핵심 파일:

- `AI_HANDOFF.md`: 작업 배경, 코드 구조, 적용·검사·업로드 절차
- `0001-offline-balance-classification.patch`: 11개 파일을 한 번에 적용하는 Git 커밋 패치
- `changes/`: 수정된 11개 파일의 최종 내용. 전체 저장소가 아니므로 이 폴더 자체를 새 저장소로 올리지 않습니다.
- `verification/`: 검사 결과, 환경 정보, 새 복제본 적용 검사
- `previews/`: 상향·하향·변경 사항 카드 예시
- `manifest.json`: 파일별 SHA-256과 커밋 정보

이 패키지 하나에 이전 문서 수정과 무료 분류 코드 수정이 모두 들어 있습니다. 예전 ZIP이나 패치를 추가로 적용할 필요가 없습니다.
